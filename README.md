1. Git, GitHub, dan Prompt Engineering (Git & Github.pdf)
Presentasi ini dibawakan oleh Nugi Farhan (Senior Product Designer) dengan fokus pada cara memanfaatkan AI secara efektif dan mengelola perubahan kode menggunakan Git.

Prompt Engineering: Membahas cara merancang instruksi agar AI memberikan hasil yang akurat. Struktur prompt yang baik meliputi Role (Peran), Task (Tugas), Context (Konteks), dan Format (Keluaran). Penggunaan konteks yang spesifik sangat penting untuk menghindari jawaban yang terlalu umum.   

Git vs GitHub:

Git: Version Control System (VCS) terdistribusi yang berjalan secara lokal untuk melacak perubahan kode.   

GitHub: Platform berbasis web untuk menyimpan repositori Git secara online dan mendukung kolaborasi.  

Git Workflow & Commands: Alur kerja melibatkan Working Directory, Staging Area, hingga Git Directory (Repository). Perintah esensial meliputi git init, git add, git commit, git push, dan git pull. Presentasi ini juga memuat panduan instalasi Git, VS Code, serta pembuatan dan konfigurasi SSH Key untuk autentikasi GitHub.

4. Kurikulum Merdeka: MBKM & MSIB (TIK Mengajar.pptx)
Panduan bagi mahasiswa politeknik mengenai kebijakan Merdeka Belajar Kampus Merdeka (MBKM).   

Hak Belajar: Mahasiswa memiliki hak belajar di luar program studi asal hingga 2–3 semester (dikonversi hingga 20 SKS per semester).   

8 Bentuk Kegiatan Pembelajaran: Pertukaran pelajar, magang/praktik kerja, asistensi mengajar, penelitian/riset, proyek kemanusiaan, kegiatan wirausaha, proyek independen, dan membangun desa/KKN.  

Program Unggulan (MSIB): Magang dan Studi Independen Bersertifikat yang memberikan pengalaman langsung di industri mitra dengan bimbingan mentor profesional.   

Metode Pembelajaran di Kelas: Menggunakan pendekatan Project-Based Learning (PjBL), Problem-Based Learning (PBL), dan Case-Based Learning (CBL) untuk melatih pemecahan masalah nyata.
